# 功能设计文档

**版本**：V2.1.0
**归档日期**：2026-08-07
**对应 Git Tag**：v2.1.0
**V2.0.0 → V2.1.0 变更**：多线程（UI 后台化 + 预计算并行）、大点云自动保护、点云信息双版本、耗时统计体系、重建后台化、默认参数自适应


## 1. 开发环境

- **IDE**：Visual Studio 2026（工具集 v145）+ Qt Creator（界面设计）
- **构建**：CMake（命令行 4.4 配置，VS 生成）
- **核心库**：Qt 6.11.0 | PCL 1.15.1 | VTK 9.4（自编译，Debug/Release 分离，-gd 后缀匹配 PCL）
- **依赖**：mypcllib（静态库，算法实现层，`add_subdirectory` 子工程挂载，改库一次生成自动重链）


## 2. 已实现功能

### 工具栏
- **打开**：根据当前 Tab（单个/多幅）自动切换加载模式，支持 .pcd / .ply
- **保存**：按当前 Tab 保存对应数据，自动创建时间戳文件夹
  - 单点云：原始点云 + 法向量点云 + Mesh
  - 多幅点云：原始点云 + 粗配准结果 + 精配准结果（有则保存）
- **撤销**：支持撤销上一步操作，最多保存 20 步历史
- **清空**：一键清空当前所有数据
- **居中显示**：已实现（原子标志通知渲染线程）
- **点云信息**：
  - 信息栏简化版（文件名 / 点数 / 宽高 / XYZ 范围 / 平均间距 / 法线状态）
  - 「完整点云信息」弹窗（详细版，可滚动：File / 点数 / 宽高 / Is Dense / XYZ / Box Size / Centroid / 平均间距 / 变异系数）
- **完整日志**：弹窗查看完整运行日志
- **工具说明**：显示软件功能简介


### 单点云处理

**预处理**（默认参数自适应 = 2×平均点间距，小数位 4）
- 无效点去除
- 体素降采样（默认 2×平均间距）
- 均匀滤波（默认 2×平均间距）
- 直通滤波（用户选择轴和范围）
- 统计离群点去除（用户输入 k 和标准差倍数）
- 半径离群点去除（默认 2×平均间距）
- MLS平滑（默认 2×平均间距）

**法向量特征处理**
- 法向量估计（默认 2×平均间距，带耗时统计）
- 法线方向一致化（用户输入邻域点数）
- 法线向视点翻转（固定视点原点）
- 法线混乱度评估（抽样加速 MAX_EVAL=20000，输出混乱度数值 + 耗时；含 normals/cloud 大小一致性防御）

**表面重建**（后台执行，UI 不卡）
- 贪婪投影三角化（后台 + 耗时统计）
- 泊松重建（后台 + 耗时统计）
- 重建误差评估（point 模式，输出误差 + 耗时；库内自带 face 模式但 O(N×M) 太慢未启用）


### 多幅点云处理（全部后台执行，UI 不卡）
- 多幅点云加载（多选文件，批量导入，侧边栏列表）
- 批量预处理（一键：去NaN → 降采样(默认 2×第一幅间距) → 统计去噪；串行执行——并行实测变慢已回退）
- **大点云自动保护**（粗配准入口）：>10 万点弹窗提醒 → 自动去NaN → 自适应降采样(2×间距，翻倍兜底) → SOR 去噪 → 按新间距重算参数
- SAC-IA 粗配准（用户输入 FPFH/SAC 半径；迭代 800；预计算帧间并行；耗时统计每步）
- ICP 精配准（用户输入最大距离和体素；内部降采样点配准 + 1.5 倍自适应降采样）


### 可视化
- 采用“常驻独立窗口”方案，鼠标交互流畅（旋转/平移/缩放）
- 支持显示原始点云
- 支持显示法向量点云（带箭头）
- 支持显示 Mesh 网格模型
- 支持显示配准结果（原始 / 粗配准 / 精配准）
- 预处理/特征操作后自动刷新视图
- 配准结果另起独立线程显示


### 性能与多线程（V2.1.0 新增）
- **第一层（UI 后台化）**：预处理 / 粗配准 / 精配准 / 贪婪投影 / 泊松 全部 QtConcurrent 后台执行，同一时刻单任务（m_busy_running），任务期间禁用共享数据控件（配准组 / 单点云组分级禁用）
- **第二层（算法并行）**：粗配准预计算（ISS+FPFH）帧间 std::async 并行 + ISS 单线程（实测嵌套 OpenMP 超载负优化）
- **耗时统计体系**：粗配准每步（ISS/FPFH/SAC）、预处理、精配准、法线估计、混乱度、重建、重建质量
- **日志系统**：ThreadSafeLogBuf 线程安全（mutex + 容量护栏 200KB + 显示行数护栏 5000 + C 层 stderr 重定向 NUL）


### 交互界面
- 左 3 : 右 7 布局
- 左侧为 Tab 切换（单点云 / 多幅点云），内部按钮分组收纳
- 右侧上方为可视化区域，下方为日志显示区
- 顶部工具栏放置高频操作（打开/保存/撤销/清空/居中/信息/日志/说明）
- 日志系统重定向 std::cout / std::cerr（C++ 流）+ freopen 丢弃 C 层 stderr，定时刷新到界面


## 3. 遗留问题与优化方向

### 功能未完善
