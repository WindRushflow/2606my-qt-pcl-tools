# 功能设计文档

**版本**：V2.0.0
**归档日期**：2026-06-21
**对应Git Tag**：v2.0.0


## 1. 开发环境

- **IDE**：Visual Studio 2026 预览版（工具集 v145）+ Qt Creator（界面设计）
- **构建**：CMake 3.21
- **核心库**：Qt 6.11.0 | PCL 1.15.1 | VTK 9.4（PCL自带）
- **依赖**：mypcllib（静态库，算法实现层）


## 2. 已实现功能

### 工具栏
- **打开**：根据当前 Tab（单个/多幅）自动切换加载模式，支持 .pcd / .ply
- **保存**：按当前 Tab 保存对应数据，自动创建时间戳文件夹
  - 单点云：原始点云 + 法向量点云 + Mesh
  - 多幅点云：原始点云 + 粗配准结果 + 精配准结果（有则保存）
- **撤销**：支持撤销上一步操作，最多保存 20 步历史
- **清空**：一键清空当前所有数据
- **点云信息**：显示点数、坐标范围等统计信息
- **居中显示**：预留功能，当前版本暂未实现
- **完整日志**：弹窗查看完整运行日志
- **工具说明**：显示软件功能简介


### 单点云处理

**预处理**
- 无效点去除
- 体素降采样（用户输入体素大小）
- 均匀滤波（用户输入采样半径）
- 直通滤波（用户选择轴和范围）
- 统计离群点去除（用户输入 k 和标准差倍数）
- 半径离群点去除（用户输入半径和最小邻域点数）
- MLS平滑（用户输入搜索半径）

**法向量特征处理**
- 法向量估计（用户输入搜索半径）
- 法线方向一致化（用户输入邻域点数）
- 法线向视点翻转（固定视点原点）
- 法线混乱度评估（输出混乱度数值）

**表面重建**
- 贪婪投影三角化（用户输入搜索半径）
- 泊松重建（用户输入重建深度）
- 重建误差评估（输出误差数值）


### 多幅点云处理
- 多幅点云加载（多选文件，批量导入）
- 批量预处理（一键执行：去NaN → 降采样 → 统计去噪）
- SAC-IA 粗配准（用户输入 FPFH 半径和 SAC 半径）
- ICP 精配准（用户输入最大距离和体素大小）


### 可视化
- 采用“常驻独立窗口”方案，鼠标交互流畅（旋转/平移/缩放）
- 支持显示原始点云
- 支持显示法向量点云（带箭头）
- 支持显示 Mesh 网格模型
- 支持显示配准结果
- 预处理/特征操作后自动刷新视图
- 配准结果另起独立线程显示


### 交互界面
- 左 3 : 右 7 布局
- 左侧为 Tab 切换（单点云 / 多幅点云），内部按钮分组收纳
- 右侧上方为可视化区域，下方为日志显示区
- 顶部工具栏放置高频操作（打开/保存/撤销/清空/居中/信息/日志/说明）
- 日志系统重定向 std::cout / std::cerr，定时刷新到界面


## 3. 遗留问题与优化方向

### 功能未完善
- 点云拼接功能尚未实现
- 多幅点云加载后侧边栏未展示文件列表
- 居中显示功能未实际实现
- “原始未配准多幅点云”可视化模式未实现

### 算法待优化
- ICP
- 法向量计算对噪声敏感，可增加前置平滑步骤

### 性能与体验
- 日志刷新存在轻微卡顿
- 大型点云处理未做多线程优化
- 缺少耗时统计与性能检测

### 环境问题
- `pcl::concatenateFields` 在当前编译器下存在模板编译错误，法线合并保存功能已被注释
- 独立窗口未嵌入 Qt 界面，长期可考虑重新编译 VTK 开启 Qt 支持
- `new_mainwindow` 相关文件为早期实验代码，后续可清理
