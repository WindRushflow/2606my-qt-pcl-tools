## 功能
### 工具栏
1. 点云读写
   - **打开**：根据当前tab判断是打开单个还是多幅点云
   - **保存**：根据当前tab选择保存位置，保存所有相关点云数据
     - 单个点云tab：原始点云、法向量点云、mesh网格模型
     - 多幅点云tab：原始点云、合并结果、粗配准结果、精配准结果（有则保存，无则跳过）
     - 创建时间戳文件夹，存入数据

### 单个点云处理
   
1. 基础辅助功能
   - 查看点云点数、坐标范围等基础统计信息
   - 支持操作撤销，保留操作历史，提升交互体验
   - 集成日志系统，实现日志重定向与定时刷新，方便调试与运行状态查看。

2. 点云预处理模块：
   - 无效点去除
   - 体素降采样
   - 均匀滤波
   - 统计/半径离群点去除
   - MLS平滑，实现点云清洗与优化。

3. 法向量特征处理模块
   - 实现点云法向量估计
   - 法线校正（方向一致化、向视点翻转）
   - 法线混乱度评估，优化法向量计算效果与质量。

4. 表面重建模块
   - 贪婪投影三角化
   - Poisson泊松两种核心重建算法
   - 重建误差评估，验证重建模型精度。
